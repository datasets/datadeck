# DataDeck

A person working with tabular data should be able to open a file, see its shape and values immediately, and answer a question without preparing a notebook. The desktop viewer accepts local and online CSV, Parquet and Excel data.

A dataset inspection session starts with the source table. A column summary supports visual exploration. A query expresses a precise question or transformation. A saved query lets a person or an AI agent repeat the same operation on another input. Original files stay available throughout the workflow.
