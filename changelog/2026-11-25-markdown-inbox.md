Each saved web link now has its own Markdown file in `~/.config/datadeck/inbox/`. The note is the body, and the YAML frontmatter carries the original URL, title, capture time and discovered resources. Open the inbox directly from the Library, edit a note with another tool, and see the change when you return. Existing SQLite captures are imported on upgrade. [Explore the storage format](https://github.com/datasets/datadeck/blob/main/docs/storage.md).
