Drop a web link into DataDeck to save it alongside your notes. Open the Library to revisit a visualization, inspect files linked from an article, or return to the table you were exploring. The project also has a tagged release workflow for signed, notarized macOS downloads. [Read the release guide](https://github.com/datasets/datadeck/blob/main/docs/releases.md).
